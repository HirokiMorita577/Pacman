## ハイパーパラメータ一覧 (全実験で固定。γ は実験3でのみ変える)

| 変数名 | 日本語名 | 値 |
| --- | --- | --- |
| lr | 学習率 α (Adam) | 0.0005 |
| gamma | 割引率 γ | 0.99 (実験3で比較) |
| epsilon_start → end | 探索率 ε (最初 → 最後) | 1.0 → 0.0248 |
| epsilon_decay | ε の減衰 | エピソードごとに掛ける。全体の40%で下限に届く値 |
| batch_size | 1回の学習で使う経験の数 | 128 |
| buffer | 経験再生バッファ | 100,000 |
| target_update | ターゲットネットワークの更新間隔 | 1,000 学習ステップ |
| network | ネットワーク | 入力 1,699 → 512 → 256 (共有) → 頭ごとに 128 → 4 (ReLU) |
| heads | HRA の頭 | 3つ (dot / ghost / move)。行動は3つの頭の Q の合計で選ぶ |
| q_scale | Q値のスケール | 報酬をエサ1個の報酬で割って学習 (エサ1個 = 1)。Q の初期値はネットワークの初期値 (≈0) |
| loss | 損失 / 更新式 | Double DQN, Huber 損失, 勾配を 1.0 で切る |
| max_steps | 1エピソードの上限 | 1,000 ステップ (または全エサ・捕獲で終了) |
| actions | 行動 | 4 (上下左右)。壁に向かうとその場に留まる |
