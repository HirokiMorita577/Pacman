# DQN と Double DQN の発表用データ

## 実験の問い

同じパックマン環境・報酬・ネットワーク・学習量で、DQN と Double DQN の更新方式だけを変えると、スコアとクリア率はどう変わるか。

- 環境：ゴースト4体、残機3、1エピソード最大1,000ステップ。
- 学習：各方式5 seed（101、202、303、404、505）、各試行200,000環境ステップ。探索は指数減衰、学習率0.0005、割引率 γ=0.95、バッチ128、ターゲット更新1,000ステップ。ネットワークのパラメータ数は両方式とも1,068,932。
- 報酬設定は共通。通常えさ+10、パワーえさ+50、ゴースト捕食+200、死亡-100、クリア報酬0。その他の形成報酬も同じ設定。
- 方法の差：DQNはターゲット網の最大Q値で次状態を評価する。Double DQNはオンライン網で行動を選び、ターゲット網でその行動を評価する。実装は `experiments/agents.py` の `td_targets`。
- 最終評価：学習に使用していない共通の評価seed 1,000,000〜1,000,099を、各学習seedの最終モデルで100回実施。各方式500評価エピソード。

## 発表で示す主結果

| 最終評価指標 | DQN | Double DQN | 差（DQN − Double DQN） |
| --- | ---: | ---: | ---: |
| 平均ゲームスコア | 2,526.2 | 2,472.3 | +53.9 |
| クリア率 | 78.8% | 78.4% | +0.4ポイント |
| 共通基準での平均報酬 | 2,383.4 | 2,299.7 | +83.7 |

差の探索的95% bootstrap区間（同じ学習seedの5組を対応づけ、seed単位で再標本化）は、スコアが **−166.4〜+274.2点**、クリア率が **−10.4〜+11.2ポイント**。このデータだけで一方が優位とは言えない。ゲームスコアとクリア率の差は小さく、seedによって優劣が入れ替わる。

## グラフ

1. `01_training_score.png`：探索を含む学習中のゲームスコア。各seedで直近100エピソード平均を計算し、5seedで平均。
2. `02_training_clear_rate.png`：同じ学習中のクリア率。
3. `03_evaluation_score.png`：学習途中の探索なし評価スコア。各チェックポイントで10評価エピソード。5seedの共通する学習エピソード範囲だけ線形補間して平均。
4. `04_evaluation_clear_rate.png`：同じ探索なし評価のクリア率。
5. `05_heldout_summary.png`：未使用の最終評価100回/seedによるスコアとクリア率。

すべての折れ線グラフの横軸は**学習エピソード数**。淡色の帯と最終評価の黒い誤差線は、5学習seedの平均に対する探索的95% bootstrap区間。学習中の曲線には探索が含まれるため、最終モデルの性能を述べるときは未使用の最終評価を使う。

## 数値データ

- `training_curve_100ep.csv`：学習中の移動平均と区間。
- `evaluation_curve.csv`：探索なし評価の補間曲線と区間。
- `heldout_seed_metrics.csv`：方式×学習seedの最終評価結果。
- `heldout_summary.csv`：方式別の最終評価平均と区間。
- `paired_difference.csv`：同じ学習seedを対応させた差と区間。
- `source_links.csv`：Google Drive上の元の10試行フォルダー、`train.csv`、`learning_curve.csv`、`evaluation_final.json`、`result.json` のリンク。
- `make_graphs.py`：CSVから5枚のPNGを再生成するスクリプト。

元データはGoogle Driveの `MyDrive/DQN_Pacman_comparisons_gpu_20261020_9e75afec/results/factors/runs/`。比較条件は `results/factors/plan.json` の `algorithms` 群、条件IDはDouble DQNが `3b898ced50c16dab4474`、DQNが `749868f4ef8494ecd78e`。10試行すべてで、結果の設定と計画が一致し、最終評価ファイルのモデルSHA256が学習結果と一致した。各試行は200,000ステップと100最終評価エピソードを完了している。

## 発表時の説明例

「ゴースト4体の同じ環境で、DQNとDouble DQNを各5つの学習seedで比較しました。各試行は20万環境ステップ学習し、最後に未使用の100エピソードで評価しました。平均スコアはDQNが2,526点、Double DQNが2,472点、クリア率は78.8%と78.4%でした。seedによるばらつきが大きく、この実験ではどちらが優れているかは決められませんでした。学習途中の曲線では傾向が変わる時点もあるため、最終評価と合わせて判断します。」
