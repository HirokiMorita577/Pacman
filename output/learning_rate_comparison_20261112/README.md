# Double DQN 学習率 α の比較（発表用）

2026-11-12にGoogle Driveの本学習結果25試行から再集計した資料です。発表スライドへ貼る図は同フォルダーのPNG 5枚です。横軸を使う図はすべて**学習エピソード数**です。

## 実験条件

- Double DQN、ゴースト4体、ライフ3、同一環境・報酬・ネットワーク・その他の設定。
- 変更したのは `agent.lr` のみ：0.00001、0.0001、0.0005（基準）、0.001、0.003。
- 各条件で学習seed 101、202、303、404、505。合計25試行、**25試行すべて完了**。
- 各試行は環境ステップ200,000回。学習エピソード数は試行によって984～1,136回。
- 最終モデルを各seedで未使用の評価100エピソードにより評価。各αで計500評価エピソード。
- `result.json` と `evaluation_final.json` のモデルSHA-256一致、設定のα・seed・ステップ数、評価件数、`train.csv` の行数を照合済み。α以外の設定は25試行で一致。

## 最終評価結果

| α | 平均ゲームスコア | クリア率 | クリア数 / 500 |
|---:|---:|---:|---:|
| 0.00001 | 1,972.8 | 83.0% | 415 |
| 0.0001 | 2,302.6 | **86.4%** | 432 |
| 0.0005（基準） | **2,472.3** | 78.4% | 392 |
| 0.001 | 2,334.6 | 85.0% | 425 |
| 0.003 | 2,253.9 | 76.8% | 384 |

学習率0.0005は平均スコアが最高、0.0001はクリア率が最高でした。スコアとクリア率の最良条件は一致していません。例えば同じ学習seedで対にすると、α=0.001は基準よりクリア率が平均6.6ポイント高く、スコアは平均137.7低い結果でした。seed数は各条件5と少ないため、最適値の断定は避けてください。

## 図の使い方

1. `01_training_score.png`：探索あり学習のスコア推移。直近100エピソードの移動平均。
2. `02_training_clear_rate.png`：探索あり学習のクリア率推移。直近100エピソードの移動平均。
3. `03_evaluation_score.png`：学習途中の探索なし評価スコア。各チェックポイントで10評価エピソード。
4. `04_evaluation_clear_rate.png`：同じチェックポイントでの探索なし評価クリア率。
5. `05_heldout_summary.png`：最終モデルの未使用評価。発表の主結果に適しています。

図の線と棒は5学習seedの平均、淡色・黒線はseed単位の探索的95% bootstrap区間です。bootstrapは5 seedから復元抽出する全3,125組を列挙し、平均の2.5%と97.5%分位を使用しました。評価100回を独立な学習seed 100個として扱っていません。

学習途中の評価図は10個のチェックポイントの平均を線でつないだものです。横軸は各チェックポイントの5 seedの平均学習エピソード数です。線の中間に追加の評価が存在するという意味ではありません。学習中の図は全25試行に共通する980エピソードまでを表示しています。

## 数値表

- `heldout_seed_metrics.csv`：25試行それぞれの最終評価、学習ステップ数、学習エピソード数。
- `heldout_summary.csv`：α別の平均とbootstrap区間。
- `paired_difference.csv`：seedを対応させた基準α=0.0005との差とbootstrap区間。
- `training_curve_100ep.csv`：学習中の100エピソード移動平均とbootstrap区間。
- `evaluation_curve.csv`：途中評価のチェックポイント別平均とbootstrap区間。
- `source_links.csv`：元のDriveファイルへのリンク。
- `make_graphs.py`：上記CSVからPNGを再生成するスクリプト（Pillowが必要）。
