# 新しい100万ステップ比較系列：実行前計画

このフォルダーは**計画のみ**です。本学習はまだ開始していません。

## なぜ最初から学習するか

既存の20万ステップ試行は完了時にoptimizer・replay・乱数状態を含むチェックポイントを削除しています。保存済みモデル重みからの学習は可能ですが、厳密な継続ではありません。100万ステップで同一条件を比較する主系列はstep 0から新規学習し、20万ステップの旧結果は保持します。

## 第1段階の条件

既存の探索的に最高平均スコアだった設定と、方式間の原因切り分け用の共通条件を含む7条件です。各5学習seedで35試行、最低3,500万環境ステップ。全250条件を一律100万ステップにする場合の最低12.5億ステップより小さい範囲で先に検証します。

| 方式 | パワーえさ報酬 | γ | 役割 |
|---|---:|---:|---|
| DQN | 50 | 0.95 | 共通条件 |
| Double DQN | 50 | 0.95 | 共通条件 |
| SARSA | 50 | 0.95 | 共通条件 |
| オンラインQ学習 | 50 | 0.95 | 共通条件、未調整 |
| DQN | 50 | 0.99 | 既存結果から選んだ候補 |
| Double DQN | 10 | 0.995 | 既存結果から選んだ候補 |
| SARSA | 0 | 0.95 | 既存結果から選んだ候補 |

各条件の具体的な設定とIDは `plan.json` に固定しました。学習seedは101、202、303、404、505。検証盤面は2000000〜2000099、停滞確認盤面は2100000以降、新しい最終テスト盤面は3000000〜3000099を予約しました。旧評価盤面と区別します。

## 開始前の必須実装

- 入力構造・ネットワーク・optimizer設定の自動記録と更新診断。
- seedごとの最良検証モデル、最終再開状態、実験系譜の分離保存。
- 最低100万ステップ以降の改善停止判定と確認評価。500万ステップ上限。
- 欠損・数値異常を成功として集計しない検証。
- 短い動作確認とテスト。これらが通るまで `plan.json` を本学習に投入しない。
